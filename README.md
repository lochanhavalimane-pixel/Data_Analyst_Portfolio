# Lochan Havalimane — Data Analyst Portfolio

A high-performance editorial portfolio website tailored for **Lochan Havalimane**, designed in the brutalist editorial visual theme inspired by [ainanai.vercel.app](https://ainanai.vercel.app).

- **Aesthetics & Theme**:
  - Warm vintage editorial cream paper background (`#F4F2EB`)
  - Deep ink typography (`#161616`)
  - Editorial vermilion orange-red accent (`#DE3B27`)
  - Sharp 0px architectural borders and hairline rules (`rule-t`, `rule-b`)
  - Signature `Anton` condensed display typography (`d-hero`, `d-1`, `d-2`, `d-3`) paired with `Archivo` grotesque body copy
  - Monogram brand logo: "LH" in dark ink box with 28° vermilion diagonal slash and hover inversion
  - Animated `.link-wipe` expanding underlines on navigation and links
- **Interactive Live Data Explorer**:
  - Interactive demographic revenue visualizer based on the 3,900 transaction customer shopping behavior dataset
  - Real-time category filtering (Clothing, Footwear, Accessories)

  - Organized by Programming, Data Analytics & BI, Databases, Statistics & EDA, Machine Learning, and Developer Tools

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite 8
- **Styling**: Tailwind CSS + PostCSS + Autoprefixer
- **Icons**: Lucide React + Custom SVG Brand Icons
- **Fonts**: Google Fonts (`Anton`, `Archivo`, `JetBrains Mono`)

## 💻 Getting Started Locally

1. Open a terminal in this directory:
   ```bash
   cd C:\Users\Ashwini\.gemini\antigravity\scratch\lochan-portfolio
   ```

2. Start the local development server:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.

3. Build for production:
   ```bash
   npm run build
   ```
   The compiled static assets will be in the `dist/` directory, ready to deploy.

4. Preview production build:
   ```bash
   npm run preview
   ```

## 🌐 1-Click Deployment

### Deploying to Vercel
1. Push this repository to GitHub: `github.com/lochanhavalimane-pixel/portfolio`
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**
3. Select your repository, keep the default Vite build settings (`npm run build`, output directory: `dist`)
4. Click **Deploy**!
